# 🎮 LOREVA — Educational Adventure Game

An educational adventure game built with HTML, CSS, and JavaScript.

## 🌿 About the Game

LOREVA is an educational adventure game that combines learning and exploration through an interactive gaming experience.

## ✨ Features

- Interactive adventure gameplay
- Educational quizzes
- Pixel art visual style
- Engaging game environments

## 🛠️ Built With

- HTML
- CSS
- JavaScript
